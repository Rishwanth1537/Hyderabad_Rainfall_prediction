# Hyderabad_Rainfall_prediction
# 🌍 Weather Guide – Rainfall Prediction in Telangana

This project is a **Machine Learning + Streamlit Web App** that fetches live weather data and predicts rainfall intensity for Telangana districts.


## 🚀 Features
- 🌡 **Live Weather Info**: Get real-time temperature, humidity, and wind speed for any city worldwide.
- 🌧 **Rainfall Prediction**: Predicts rainfall (in mm) + gives a descriptive output (Light/Moderate/Heavy Rain).
- 📊 **Machine Learning**: Uses regression and classification pipelines.
- 🌐 **API Integration**: OpenWeather API for real-time weather data.


## 🛠 Tech Stack
- Python (pandas, numpy, requests, joblib)
- Streamlit (Interactive UI)
- OpenWeather API
- Machine Learning (Regression + Classification)


## 📂 Project Structure
- `Hyderabad_Rainfall_Prediction.ipynb` – Model training & analysis.
- `Final_Weather_Data.csv` – Processed dataset for training.
- `Rainfall prediction in hyd.py` – Streamlit App code.
